# AIHUB_TEST_DB-gated test functions: the ratchet for the aihub#303 DB-test
# coverage gate (see internal/citest/dbtestcov/main.go, and aihub#320 for why
# this file is a set of names rather than the `-min-gated N` integer it
# replaced).
#
# One line per top-level test function that SKIPs for want of a database:
#
#     <module-relative package> <TestName> [+EXTRA_ENV ...]
#
# A trailing `+VAR` records that the test's own skip message asks for more than
# a database, so CI cannot run it and no CI step may name it. Sorted, one entry
# per line, no duplicates — all three are enforced.
#
# The gate demands that this file EQUAL the measured inventory, so:
#
#   * adding a DB-gated test means adding its line here (the gate prints the
#     exact line to paste), and
#   * removing one means deleting its line here, in the same change. That
#     deletion is the point: it is the reviewable record of which DB coverage
#     was deliberately given up. Nothing regenerates this file for you.
#
# Provenance lives in `git blame`, not in a prose changelog: the line and the
# commit that added the test are the same diff.
